# Inventario_De_Papeleria
## Descripcion del proyecto final.
### Hoy en día muchas papelerías todavía llevan el control de productos y ventas de manera manual, ya sea en libretas, hojas o incluso de memoria. Esto puede causar muchos problemas como pérdida de información, errores en cuentas, productos faltantes o dificultad para saber qué mercancía hace falta comprar.
### Por eso se desarrolló este proyecto, que consiste en crear una base de datos en MongoDB para organizar toda la información importante de una papelería. El sistema ayudará a tener un mejor control de productos, clientes, ventas, compras y proveedores de manera más rápida y ordenada.
### La base de datos fue creada en MongoDB porque es una herramienta flexible y fácil de utilizar para guardar información mediante documentos JSON.
